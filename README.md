# مشق‌یار

نسخه‌ی اندرویدی مشق‌یار، اپ یادآوری مشق‌های مدرسه با برنامه هفتگی، تم روشن و تاریک و تنظیمات شخصی‌سازی.

این پروژه در حال حاضر شامل پوسته‌ی اندروید و رابط تعاملی مشق‌یار است. برای ساخت خودکار APK باید فایل workflow در مسیر `.github/workflows/build-apk.yml` اضافه شود؛ اتصال فعلی GitHub مجوز نوشتن workflow ندارد.
